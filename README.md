# ApexPlanet Internship – Task 1

## Basics of Web Development

This repository contains my **Task 1 submission** for the Web Development Internship at **ApexPlanet Software Pvt. Ltd.**

### Objective
Learn and apply the foundational concepts of:
- HTML
- CSS
- JavaScript

### Task Requirements

#### 1. Create a Simple Webpage Using HTML
- Use basic HTML elements and structure
- Add headings, paragraphs, images, and links

#### 2. Style the Webpage Using CSS
- Apply colors and fonts
- Add spacing and layout adjustments
- Improve the overall appearance of the webpage

#### 3. Add Basic JavaScript Interactivity
- Implement simple JavaScript functionality
- Add a button that triggers an alert message when clicked

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

Through this task, I strengthened my understanding of the fundamentals of web development and gained practical experience in combining HTML, CSS, and JavaScript to create an interactive webpage.
